## Current-pass QA note

This pass reused the initial empty analysis as `QA Sample Pump 001`, with a clearly marked synthetic PM `QA ONLY - Non-operational placeholder` that remains Draft. It also created `QA ONLY SAMPLE EQUIPMENT - ` followed by 33 X characters (60 characters total), which is at Evidence, and `QA ONLY - Start and API error test`, which is at Asset Proposal. Those two later analyses are labeled QA-only. No QA analyses were deleted. The project JWT lifetime was temporarily changed to 300 seconds for token issuance and restored to 3600 seconds; a read-back confirmed the restored value. No independent SQL query or exact planner-row count was run.

# PlannerMC replica-diff

**Status:** research
**Date:** 2026-10-31

## Objective

Assess the current PlannerMC implementation against the agreed MVP feature scope and report the limits of competitor and visual comparisons.

## Scope

- Validate the existing feature matrix and repair CSV syntax needed by the installed parity tool.
- Calculate weighted PlannerMC scope coverage from rows marked `plannermc_spec=yes`.
- List incomplete in-scope capabilities in a practical build sequence.
- Assess whether original screenshots support layout comparison.
- Record what cannot be concluded from the current two-vendor evidence matrix.

## Boundaries

- Do not turn `no evidence` into a claim that a competitor lacks a feature.
- Do not present the combined iMPS/GWOS matrix as a single original application.
- Do not create or infer visual scores without same-screen, same-state reference captures.
- Do not change PlannerMC product code in this research step.

## Acceptance

- `replica/parity.md` labels its scope score and method, reports missing requirements and a next build recommendation, and states unscored comparisons.
- The feature matrix parses as CSV.
- The tracking issue and map record findings and limits.

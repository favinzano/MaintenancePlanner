# Public product and visual-brand reconnaissance

Type: research
Status: resolved
Triage: ready-for-agent
Blocked by: none

## Request

Compare the published capabilities of Innovapptive iMPS and Prometheus GWOS-AI with the current PlannerMC MVP specification, and record the user-requested MacroCap Operations visual reference.

## Scope and method

- Read the local PlannerMC specification, constitution, domain guidance, issue-tracker guidance and triage labels.
- Used official product pages from Innovapptive and Prometheus Group for product claims.
- Observed MacroCap Operations Daily Overview in the already-open browser session and its sign-in brand image in a separate unauthenticated browser view. No form was submitted, no login was attempted, and no operational records were copied into the deliverables.
- Did not access private product demos, product APIs, source code or customer data.

## Answer

Completed the comparative recon in [replica/recon.md](../../../replica/recon.md), its feature matrix in [replica/features.csv](../../../replica/features.csv), and the user-requested style reference in [replica/brand-reference.md](../../../replica/brand-reference.md).

[Inference] iMPS is the closest public reference for evidence-backed work-package assembly and readiness gates. GWOS-AI is the closest reference for work-order planning, templates, materials, crews, schedules and ERP-linked workflows. Neither source set establishes that the product produces PlannerMC's manual-grounded, English, 15-step PM output with bilingual voice/text, source annotations, draft retention and manual CMMS copy.

The MacroCap reference records the observed MacroCap Labs wordmark and logo asset, Geist Variable, measured dark-theme CSS tokens, outline icon style, and Daily Overview layout. The logo values from the compressed AVIF are identified as approximate samples. The light palette and icon package remain unverified.

The recon does not change the PlannerMC MVP specification or implement a screen. Use the brand-reference document during the design phase.

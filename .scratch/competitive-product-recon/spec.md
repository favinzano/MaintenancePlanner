# Recon de productos de planificación y referencia visual

**Estado:** alcance de investigación acordado
**Fecha:** 2026-10-29

## Objetivo

Comparar las funciones que Innovapptive iMPS y Prometheus GWOS-AI describen públicamente con la especificación vigente de PlannerMC. Registrar además la identidad visual de MacroCap Operations como referencia solicitada para PlannerMC.

## Usuario y contexto

Maintenance Planner que prepara PMs para un equipo y sus sub-assets directos. PlannerMC produce contenido revisable que el usuario copia al CMMS.

## Alcance

- Usar páginas oficiales de los proveedores y la especificación local de PlannerMC.
- Separar declaraciones de proveedor, observaciones directas, requisitos locales e inferencias.
- Registrar los módulos y flujos descritos por proveedor; no afirmar que se observó una sesión funcional de iMPS o GWOS-AI.
- Registrar el wordmark, logo, iconografía, tipografía y tokens de color visibles en MacroCap Operations.
- Mantener a MacroCap como referencia visual y a iMPS/GWOS-AI como referencias funcionales.

## Criterios de salida

- replica/recon.md contiene alcance, fuentes, flows, componentes observados, límites y comparación cualitativa.
- replica/features.csv lista requisitos y capacidades con estados respaldados por las fuentes.
- replica/brand-reference.md contiene la referencia visual de MacroCap y las etiquetas de evidencia.
- .scratch/competitive-product-recon/map.md y este issue registran decisiones, límites y trabajo completado.
- No se cambia el alcance de specs/001-plannermc-mvp/spec.md ni se implementa interfaz o integración durante este recon.

## Restricciones de evidencia

- Las páginas de Innovapptive y Prometheus son materiales oficiales de proveedor; sus cifras comerciales no se tratan como resultados independientes.
- No usar cuentas, APIs privadas, código, datos de clientes ni pantallas de demostración restringidas de iMPS o GWOS-AI.
- En la referencia MacroCap, registrar solo elementos visuales pertinentes. Excluir los valores operativos y nombres de registros que se vean en la sesión autenticada.
